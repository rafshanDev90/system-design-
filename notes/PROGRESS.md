## Node.js Context

As a Node.js backend developer, these concepts will be especially relevant:

- **Event loop** → Understanding async processing and event-driven architecture
- **Express/Fastify** → Reverse proxy and application layer concepts
- **MongoDB/PostgreSQL** → Database choices (NoSQL vs SQL)
- **Redis** → Caching patterns
- **PM2/Docker** → Horizontal scaling and load balancing
- **REST APIs** → Communication patterns
- **VPS deployment** → Understanding infrastructure from the ground up

## Key Questions to Ask Yourself

For each topic, ask:
1. How would I build this in Node.js today?
2. Where would my current approach break at scale?
3. What would I add/change to make it scalable?
4. What are the trade-offs?
