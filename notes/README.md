# System Design Notes

> Study notes based on [donnemartin/system-design-primer](https://github.com/donnemartin/system-design-primer)
>
> **Background**: Junior backend developer transitioning from Node.js API development to system design.

## Directory Structure

| Folder | Topics |
|---|---|
| `00-start-here/` | Scalability intro, how to approach system design |
| `01-fundamentals/` | Performance vs scalability, latency vs throughput, CAP theorem, consistency patterns |
| `02-core-concepts/` | DNS, CDN, Load balancer, Reverse proxy, Horizontal scaling |
| `03-infrastructure/` | Application layer, Microservices, Service discovery |
| `04-application/` | Application caching, cache-aside, write-through, write-behind |
| `05-database/` | RDBMS, NoSQL, SQL vs NoSQL, sharding, replication |
| `06-cache/` | Caching strategies, CDN caching, database caching |
| `07-asynchronism/` | Message queues, task queues, back pressure |
| `08-communication/` | TCP, UDP, RPC, REST |
| `09-security/` | Security principles |
| `10-solutions/` | Pastebin, Twitter, Web Crawler, Mint, Social Graph, etc. |
| `11-ood/` | Hash map, LRU cache, Call center, Parking lot, etc. |
| `12-appendices/` | Powers of two, latency numbers, real-world architectures |

## How to Use

1. Read the corresponding section in `../system-design-primer/README.md`
2. Write your own notes in the respective folder
3. Solve the related practice problem
4. Review Anki flashcards from `../system-design-primer/resources/flash_cards/`
